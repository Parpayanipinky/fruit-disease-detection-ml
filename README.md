# Fruit Disease Detection System

A Machine Learning-based application that identifies fruit diseases from uploaded images using a trained deep learning model. The system helps detect diseases quickly and accurately, making it useful for learning, research, and smart agriculture applications.

---

## Features

- Detects fruit diseases from images
- Deep learning-based image classification
- Simple and user-friendly interface
- Fast and accurate predictions
- Trained model included for inference

---

- Python
- TensorFlow / Keras

- CSS

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/fruit-disease-detection-system.git
```

Navigate to the project folder:

```bash
cd fruit-disease-detection-system
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python webapp/app.py
```

---

## Usage

1. Launch the application.
2. Upload an image of a fruit.
3. The model analyzes the image.
4. The predicted disease is displayed.
